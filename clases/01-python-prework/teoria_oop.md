# Teoria OOP (resumen didactico)

## Clase vs instancia
- Clase: plantilla o molde.
- Instancia: objeto real creado desde la clase.

## Atributos vs metodos
- Atributos: datos del objeto (estado).
- Metodos: acciones que el objeto puede ejecutar.

## __init__ y self
- `__init__` es el constructor.
- `self` representa al objeto actual.

## Encapsulacion
Agrupar datos y acciones en la misma clase ayuda a ordenar el sistema.

## Reglas practicas
- Una clase debe tener una responsabilidad clara.
- Los metodos modifican el estado de la clase.
- Usar nombres descriptivos para atributos.
