# Estructura del repo Hub

## Objetivo
Este repo centraliza recursos y clases base para el programa.

## Carpetas
- `clases/`: materiales por clase.
- `docs/`: guias de uso y estructura.

## Convencion
- Una carpeta por clase: `clases/01-*`, `clases/02-*`.
- Subcarpetas sugeridas: `notebooks/`, `codigo/`, `planes_clase/`, `assets/`.
