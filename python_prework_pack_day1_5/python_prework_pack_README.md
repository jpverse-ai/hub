# Python Prework (Día 1–5) — Paquete de clases + desafíos

Este paquete incluye, por cada día:

- **`dayX_class_plan.md`** → guía del profesor (agenda, demos, errores comunes, checklist)
- **`dayX_challenges.py`** → archivo para el alumno (4 retos graduales con asserts)
- **`dayX_solutions.py`** → soluciones (teacher) + asserts extra

## Cómo usar (modo alumno)
1. Abre `dayX_challenges.py`
2. Implementa los `TODO`
3. Ejecuta:
   ```bash
   python dayX_challenges.py
   ```
4. Si un `assert` falla, ajusta tu solución.

## Cómo usar (modo profesor)
- Sigue `dayX_class_plan.md` como guion.
- Usa `dayX_solutions.py` para:
  - mostrar una solución “limpia”
  - discutir casos borde
  - comparar enfoques (loop vs comprehension, etc.)

## Nota sobre “La sesión del intérprete de código ha caducado”
Eso suele significar que el entorno donde estabas ejecutando código (por ejemplo, un notebook o Code Interpreter)
se reinició por inactividad o por límite de tiempo. Se pierden variables y estado en memoria, pero **los archivos
guardados en disco** (como estos `.py` y `.md`) siguen existiendo si los descargaste o si permanecen en tu carpeta.
